第一章 · 产品定义与核心理念

1.1 产品灵魂

“像打字一样简单，像看好莱坞大片一样震撼”
  • 极致封装：用户下载 .exe 或 .dmg，双击下一步到底，不需要懂 Python、Cuda 或环境变量。
  • 沉浸式体验：全屏无噪点 UI，隐藏所有技术术语（如“潜空间”“VAE解码”），只保留人类能听懂的语言。
  • 本地与云端无感切换：用户不关心算力来源，只关心“生成速度快不快”。

1.2 目标用户画像

  • 短视频博主：快速生成视频素材，零代码基础。
  • 电商卖家：将产品图变成动态展示视频。
  • 普通白领/学生：做 PPT 或社交媒体，用 AI 生成炫酷背景。

第三章 · 核心功能规划（小白视角）

3.1 模式一：一句话出片（首页默认）

  • 交互：中央超大输入框，占屏幕 70%。
  • 用户操作：输入 “赛博朋克风格的猫在雨中走” → 点击【生成】。
  • 后台：自动调用 T2V 预设工作流，默认生成 3 秒视频（防爆显存），生成后循环预览。

3.2 模式二：图生视频与动效（电商/设计专用）

  • 交互：上传图片 + 描述运动（如“镜头缓慢推进，头发飘动”）。
  • 核心：AnimateDiff + ControlNet (Tile/IP-Adapter) 工作流。
  • 封装：前端仅显示“运动强度”滑块（1~10），后台映射为 Denoising Strength。

3.3 模式三：视频风格化

  • 交互：上传视频 + 选择风格（油画/3D/水墨）。
  • 逻辑：Video-to-Video + ControlNet 保持原结构，只改纹理。

第四章 · 客户端封装详解（技术实现）

4.1 让 ComfyUI 成为“沉默的仆人”

禁止 ComfyUI 弹出浏览器，以后台进程运行：

# Tauri 后端启动子进程（隐藏窗口）
python main.py --headless --port 8188 --windows-foreground

4.2 写一个“翻译官”服务（核心胶水代码）

FastAPI 中转服务 local_server.py，接收前端简化参数，映射为 ComfyUI 复杂 JSON。

from fastapi import FastAPI
import json, requests, random

app = FastAPI()

@app.post("/generate")
def generate(request: dict):
    with open("workflows/txt2video.json", "r") as f:
        workflow = json.load(f)
    
    # 只替换用户输入，其他参数（步数、CFG）使用最优内置值
    workflow["6"]["inputs"]["text"] = request["prompt"]
    workflow["8"]["inputs"]["seed"] = random.randint(1, 1000000)
    
    resp = requests.post("http://127.0.0.1:8188/prompt", json={"prompt": workflow})
    return {"task_id": resp.json()["prompt_id"]}

4.3 本地/云端无感切换（商业命脉）

  • 本地模式：请求 → 127.0.0.1:8188
  • 云端模式：请求 → 自有云服务器（阿里云/火山引擎 A100）
  • 智能路由：检测到显存 < 6GB 时自动弹窗：“检测到您的显卡性能有限，是否开启云端极速模式？”

第五章 · 前端 UI/UX 设计规范

5.1 设计语言：毛玻璃质感 + 黑暗极简

  • 主色调：深邃黑 #0A0A0A + 霓虹蓝紫渐变。
  • 字体：无衬线大字号，远距离清晰。
  • 布局：左侧历史缩略图，中央超大输入区，右侧（可折叠）高级参数。

5.2 核心交互优化（小白感知）

  • 进度文案化：不显示“45%”，而显示“正在构思画面…”“即将完成，请稍候…”。
  • 首屏引导：背景循环播放 NexusVideo 生成的精选视频集锦，中央输入框淡入。
  • 一键重试：点击“再来一次”，自动更换随机种子（用户无感）。

第八章 · 启动前的最后忠告

  • 📦 安装包大小：因内置 PyTorch 和基础模型，初始安装包约 15GB-20GB。官网提示：“请预留 30GB 硬盘空间，建议使用 SSD”。
  • ⏳ 首次启动：解压模型文件需 2-3 分钟“初始化”，务必加进度条，避免用户误以为卡死。
  • 💡 灵感引导：输入框下方加小字提示 “试试输入：赛博朋克、电影级光影、慢动作”，或内置 10 个“灵感词汇”按钮，点击自动填入。
